One instrument, two things you can drive

The project is a 2.1 mT, 89.4 kHz proton NMR spectrometer built around the class board: a printed housing for the boards, a wound probe that holds the coil and the sample, a Helmholtz pair for the field, and firmware that turns a pulse program into a spectrum. Two interactive views let you explore it — the physical bench, and the measurement signal path. Both run entirely in your browser.

The signal path

The console is not a re-implementation — it drives the exact C++ physics/DSP/pulse core the microcontroller runs, compiled to WebAssembly. Each stage on that page is a stage of the real firmware:

Pulse program→ Gate engine→ ADC (ADS8688)→ DSP pipeline→ Spectrum

Hardware-neutral program

An experiment compiles to a small instruction stream (timing in engine ticks, phase in 1/65536 turn). The same bytes drive the RMT gate backend, the simulator and a future FPGA backend.

Deterministic gates

TX_EN, RX_BLANK and the DDS phase select are packed into RMT symbols and started on one clock edge; MCPWM capture timestamps every edge, so the timing is measured, not assumed.

Hardware-paced ADC

The ADS8688 streams over I²S at 125 kS/s per channel. I and Q are converted one aperture apart — a skew the shared DSP corrects with a fractional delay (you can toggle it on the console).

One shared receive chain

Volts → DC removal → digital mix to baseband → FIR + decimate → per-scan phase correction → coherent average → spectrum. The firmware, the host tools and the browser all run this one implementation.

Hardware & firmware

The real electronics and the current working firmware live in the course's class-board repository, which stays authoritative for the board. This project's experimental successor firmware (shared C++ core, ESP-IDF control loop) is developed under this repo's firmware/ and is not yet a replacement for the class board.

Design-stage model — not a measurement. No calibrated probe, measured FID, spin echo, or verified timing is claimed here.
