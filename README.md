# Benchtop NMR instrument (TIGP 2026, Project 3)

Yi-Tsai Liang (`tojestspacja`). This repository is the canonical home of my Project 3: a 2 mT
benchtop NMR instrument built around the course's class board.

**Project site:** <https://tojestspacja.github.io/nmr-instrument/> ·
**Interactive simulator:** <https://tojestspacja.github.io/nmr-instrument/simulator/>

> **Status: design stage.** Designed and cross-checked in OpenSCAD; nothing printed, cut or measured
> yet. Every spectrum and signal here is simulated; there are no physical measurements so far.

## What lives where

| Content | Home |
| --- | --- |
| Project narrative, CAD, fabrication files, renders, simulator, analysis | **this repository** |
| The real PCBs, ESP32 firmware, NMR pulse sequence, the instrument's own web UI | [class-board-2026](https://github.com/TIGP-Experimental-Methods/class-board-2026), pinned in [`hardware/README.md`](hardware/README.md) |
| How the course finds this project | one card on the [class showcase](https://tigp-experimental-methods.github.io/showcase-2026/), linking to the site |

The rule: changing my Project 3 → work here. Changing the real PCB, firmware, pulse sequence or
instrument UI → work in class-board-2026. Changing how the course finds the project → edit only the
showcase card.

Three interfaces, three jobs:

```text
Course showcase card           "What is this project?"            -> links to the site
This site + /simulator/         "How is it built, how does it work?" -> simulation and explanation only
instrument-XXXX.local           "Operate the real instrument"        -> served by the ESP32 on local Wi-Fi
```

The simulator does not control the board, and cannot: it is a public HTTPS page, and the instrument
is a local-network device. Real scans start at `instrument-XXXX.local` → NMR → Apply settings → Start.

## Layout

| Path | What |
| --- | --- |
| `index.html` | the project site's landing page (GitHub Pages serves this repository's root, `main`) |
| `simulator/` | NMR Bench Setup: 3D bench and Bloch-equation pulse simulator (`simulator/README.md`) |
| `mechanical/` | the OpenSCAD project: housing, probe, B0 pair, bench checks, data model, simulator `spectrum.py` (`mechanical/README.md`) |
| `fabrication/` | laser and water-jet exports and `CUT-LIST.md`, generated by `mechanical/export_cut.py` |
| `hardware/README.md` | the class-board-2026 dependency: reference commit and the exact files |
| `tools/handin.py` | writes the course hand-in copy of the housing into class-board-2026 |

The CAD previews read the board meshes from class-board-2026 cloned beside this repository
(`../class-board-2026`); see `hardware/README.md`.
